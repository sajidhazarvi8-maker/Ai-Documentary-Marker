# AI Documentary Maker — Free MVP

## Run
1. Extract this ZIP.
2. Open `index.html` in Chrome for a quick test (some PWA features require HTTPS).
3. For installable PWA, upload the folder to a free static host that supports HTTPS, such as GitHub Pages.
4. Open the HTTPS website in Chrome Android → menu ⋮ → Install app / Add to Home screen.

## Included in this first prototype
- Paste a script and split paragraphs into scenes.
- Attach one image or video per scene.
- Image motion, scene captions, cinematic colour filters and fade/cut transitions.
- Optional voice-over and music audio files.
- Browser-based video rendering where MediaRecorder is supported.
- Local processing; this app does not upload your files.

## Honest limitations
This is a working editing prototype, not the complete AI generator requested. It does not yet generate original AI images/video, write scripts, or synthesize a downloadable voice track. Free AI generation at scale cannot be promised. Browser export may produce WebM rather than MP4 depending on Android browser support.

## Important
Keep the screen awake during rendering. Test with a short 2-scene project first. Do not use a shared shop computer for private scripts or personal media.
